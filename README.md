# psy-match: странные вопросы

Лёгкий сайт со странными вопросами на два варианта. После 7 ответов показывает психологический портрет (5 шкал), барометр совпадения с остальными участниками и сколько вопросов человек осилил по сравнению с другими.

Сайт: https://nicknameantares.github.io/psy-match/

- `index.html` — вся страница: вёрстка, встроенные вопросы (массив `BASE`), портреты (`TYPES`), логика.
- `questions.json` — дополнительные вопросы, подгружаются при открытии. Чтобы добавить вопрос, допиши объект `{id, ax, e, a, b}`: `ax` — шкала (`brave`, `heart`, `social`, `chaos`, `dream`), `a` — вариант на полюс «+» (смелость, сердце, компания, хаос, мечты), `b` — на полюс «−». `id` из латиницы и цифр, не меняй его у уже опубликованных вопросов.

Ответы анонимные: у каждого браузера свой случайный id. Они хранятся retained-сообщениями на публичных MQTT-брокерах (broker.emqx.io и broker.hivemq.com) в топике `strange-questions/v1/a/<id>`. Это бесплатно и без регистрации, но брокеры тестовые: они не гарантируют, что данные проживут вечно.
